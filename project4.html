Smart Battery Algorithms Research

R Machine Learning Data Analysis

Description

Developed a predictive peak-shaving control algorithm for a simulated 2 MWh / 1 MW campus battery system that estimates optimal daily discharge thresholds from prior-day energy usage. Using 2019-2023 training data and testing the correlation of dozens of variables I was able to acheive a linear correlation model with an R² value of 0.72. The model reshaped demand peaks and achieved $13,049 in simulated 2024 cost savings, demonstrating the effectiveness of lightweight predictive energy-management strategies.
